MIA Shopping Agent

Локальный ИИ-агент для исследования товарных предложений в разработке

MIA помогает сравнить товары по одному поисковому запросу: собрать предложения из доступных источников или загрузить их вручную, привести к единому виду, сопоставить одинаковые модели, сравнить цены с учётом доставки и сформировать объяснимую рекомендацию. Каждый вывод опирается на конкретные данные — если параметр неизвестен, он помечается как неизвестный, а не подставляется наугад.

Что уже подтверждено

  • Локальное приложение: backend на FastAPI, интерфейс на React/TypeScript, хранение в PostgreSQL.
  • Ручной импорт предложений: текст, CSV, JSON и ссылка на карточку товара.
  • Детерминированный Rule Engine: проверки допустимости, состояния предложений, объяснение решения.
  • Ранжирование в трёх режимах (личная покупка, перепродажа, сезонные закупки) с разложением балла по компонентам.
  • Хранение истории наблюдений цен и результатов анализа в PostgreSQL.
  • Локальная языковая модель (Ollama) подключается по требованию и не используется для арифметики и решений о допустимости.
  • Сквозной сценарий проверен тестами: автотесты backend, интеграционные тесты PostgreSQL, браузерные E2E.

Чего пока нет

  • Прямой интеграции с Wildberries, Ozon, Яндекс Маркет и Авито — официального доступа к каталогу для покупателя у этих площадок нет, поэтому такие источники не заявлены как работающие.
  • Автоматического мониторинга цен по расписанию через внешний источник: подключение появится после подтверждения условий доступа.
  • Публичного доступа к приложению: MIA работает локально на компьютере пользователя, без облачной инфраструктуры.

Как предполагается использовать

  1. Пользователь задаёт товар и критерии (цена, состояние, комплектация, сроки).
  2. Добавляет предложения вручную или из разрешённого источника.
  3. MIA сопоставляет модели, сравнивает цены и показывает, на чём основан вывод.
  4. Результат сохраняется локально, чтобы можно было вернуться к нему позже.

Ограничения

Проект находится в активной разработке. MIA не выполняет покупки, оплату или оформление заказов. Данные о товарах не публикуются и не перепродаются. Приложение не размещается в открытом доступе и не собирает персональные данные посетителей этой страницы. Указанные возможности отражают фактическое состояние проекта на момент публикации страницы и могут меняться.
