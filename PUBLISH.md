# Публикация страницы MIA Shopping Agent

Статический сайт для GitHub Pages и проверки площадки паблишера (Такпродам). Backend, PostgreSQL, Ollama
и внутренние API **не публикуются** — только содержимое этого каталога.

## Что здесь есть

- `index.html` — единственная страница, семантическая разметка и SEO-метатеги;
- `styles.css` — дизайн-система и адаптивная вёрстка (без внешних зависимостей);
- `app.js` — мобильное меню, состояние шапки и год в подвале (без сетевых запросов);
- `og-image.png` — изображение для Open Graph и карточек соцсетей;
- `shots/` — скриншоты проверки на 1920 / 1280 / 768 / 390 px и открытое мобильное меню;
- `PUBLISH.md` — эта инструкция.

Секретов, токенов, паролей, персональных данных и внутренних адресов в файлах сайта нет. Страница не
обращается к MIA, маркетплейсам, аналитике и сторонним CDN.

## Проверочный метатег

В `index.html` уже установлен актуальный метатег площадки:

```html
<meta name="takprodam-verification" content="014afdba-03fb-49a7-9d80-32a7ebafc9e2">
```

Значение менять нельзя. Перед публикацией достаточно убедиться, что строка присутствует внутри `<head>`.

## Локальная проверка

```powershell
cd D:\AI_Work\mia-public-site
python -m http.server 8099 --bind 127.0.0.1
# открыть http://127.0.0.1:8099/
```

Проверить, что в исходном коде страницы есть метатег:

```powershell
(Invoke-WebRequest http://127.0.0.1:8099/ -UseBasicParsing).Content | Select-String 'takprodam-verification'
```

Проверка вёрстки и скриншоты выполнялись через Playwright с Edge (`channel="msedge"`) на ширинах
390 / 768 / 1280 / 1920 px: горизонтального скролла нет, консоль чистая, все сетевые ответы — только
собственные файлы сайта (200), меню и якорные кнопки работают.

## Публикация (на выбор, бесплатно)

### Вариант 1 — GitHub Pages (рекомендуется)

1. Создайте **отдельный публичный репозиторий** (не `market-intelligence` и не его рабочую ветку), например `mia-site`.
2. Скопируйте в него файлы сайта: `index.html`, `styles.css`, `app.js`, `og-image.png`.
3. `git init`, первый коммит, добавьте remote и выполните `git push` **в этот новый репозиторий**
   (push в MIA запрещён без отдельного разрешения).
4. Settings → Pages → Source: `Deploy from a branch` → branch `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты страница будет доступна по адресу `https://<account>.github.io/mia-site/`.

Канонический адрес в метатегах: `https://alex-ander-ho.github.io/mia-site/`. Если репозиторий или
аккаунт другие — обновите `canonical`, `og:url`, `og:image` и `twitter:image` в `index.html`.

### Вариант 2 — Netlify Drop / Cloudflare Pages

Перетащите папку с файлами сайта в Netlify Drop (без регистрации для черновика) или подключите репозиторий
в Cloudflare Pages (бесплатный план, статический хостинг).

### Вариант 3 — любой статический хостинг

Достаточно разместить `index.html`, `styles.css`, `app.js` и `og-image.png` в корне домена или поддомена.
Серверная часть не нужна.

## Проверка после публикации

1. Открыть URL в браузере (в том числе в приватном окне).
2. Просмотреть исходный код страницы (Ctrl+U) и убедиться, что метатег на месте.
3. Проверить, что при открытии нет запросов к `127.0.0.1`, внутренним портам и сторонним трекерам.
4. Проверить мобильное меню, якорные кнопки и отсутствие горизонтального скролла.
5. Только после этого отправлять ссылку на проверку в Такпродам.

## Ограничения

- Публикация выполняется **вручную** владельцем: эта инструкция не публикует ничего автоматически.
- Не добавляйте на страницу контакты, ключи API, адреса внутренних сервисов и данные реальных продавцов.
- Демонстрационные предложения и цены на странице — вымышленные и помечены явно.
- Если меняются подтверждённые возможности MIA — обновляйте статусы в разделе «Возможности», не заявляя
  неподключённые источники как работающие.
